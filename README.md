## RenderX

RenderX to projekt składający się z aplikacji frontendowej oraz backendowego API.

- **Frontend**: Next.js (folder `frontend`)
- **Backend**: Django REST API (folder `backend`)

## Uruchomienie

- **Frontend**
  - Wejdź do katalogu `frontend`
  - Zainstaluj zależności
  - Uruchom serwer deweloperski

- **Backend**
  - Wejdź do katalogu `backend`
  - Wykonaj migracje bazy danych
  - Uruchom serwer deweloperski

## Architektura

- **UI**: aplikacja SPA w Next.js
- **API**: Django z JWT oraz obsługą produktów
- **Baza danych**: relacyjna baza zgodna z konfiguracją Django
